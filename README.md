# LRC Visualizer

一个浏览器端歌词视频制作器，支持中文 LRC、字体导入、歌词从左到右变色预览，以及带背景或透明画布的可视化导出。

## 功能

- 导入音频文件和 `.lrc` 歌词文件。
- 可编辑画面中的歌名和歌手；MP3 会在浏览器本地读取常见 ID3 标题、歌手和内嵌专辑封面，封面也可手动上传覆盖。
- 自动识别常见中文歌词编码，包括 UTF-8、GB18030/GBK、Big5、UTF-16。
- 导入 `.ttf`、`.otf`、`.woff`、`.woff2` 字体，并分别设置中文/英文字体。
- 调整歌词颜色、当前歌词高亮方式、次行颜色、纯色背景和透明背景。
- 上传视频截图或参考图片后，使用本地 OKLab 感知色彩聚类提取主色，并自动生成背景、当前歌词、高亮、弱化歌词和歌曲信息颜色；图片不会上传。
- 内置 Sunset Bloom、Apricot Mist、Sage Paper、Glacier Glass、Plum Velvet、Ink & Cream 六组颜色预设。
- 当前歌词可选择从左到右变色，或在切换到当前行时直接显示高亮最终颜色；支持普通逐行 LRC 和带逐词时间标签的 LRC。
- 多行歌词使用真实文字测量和可变高度轨道，长句会自然换行且不会挤压相邻歌词；可手动设置 3-13 行。
- 歌词可在居中与向左对齐之间切换，两种排版均与导出画面保持一致。
- 首句开始前会先展示后续歌词和歌曲信息，不再出现“等待歌词开始”的占位文字。
- 切行采用与 Folia 同类的预布局固定轨道和过阻尼弹簧相机计算；拖动、暂停、实时预览和逐帧导出在同一时间点保持一致。
- 所有歌词行使用固定字号和固定轨道间距；切行不再按距离缩放每一行，只改变整条轨道的位置与文字透明度。
- 播放时钟直接驱动画布与进度条，不再每帧触发 React 整页重渲染；拖动进度条时先实时预览，松手后只提交一次音频 seek。
- 实时预览会限制内部画布分辨率，避免全高清 Canvas 滤镜造成掉帧；最终导出仍使用设置中的完整输出分辨率。
- 使用 WebCodecs 在隐藏画布上逐帧直接编码；支持时优先生成 H.264/AAC MP4，否则使用 VP8/VP9 + Opus WebM。
- 导出不使用 `MediaRecorder`、`captureStream` 或预览录制，不受窗口切换和后台降频影响；预览与成片共用同一套画面绘制逻辑。
- 预览支持拖动播放进度条，并可快速前进/后退 5 秒。
- 可导出完整音频或自定义起止片段；画面和音频会按同一范围直接裁切。
- 支持简洁歌词页与汽水音乐卡片两种画面样式（不含短视频平台侧栏），以及 16:9、真实 1080×1920 的 9:16、1:1 输出画幅。
- 非透明背景优先生成 `.mp4`；透明背景需要浏览器支持 VP9/Opus 时生成 `.webm`。

## 本地运行

macOS 上如果尚未安装 Node.js，可以直接双击 `start-dev.command`，或在此目录执行：

```bash
zsh start-dev.command
```

安装 Node.js 后，也可以使用标准 npm 命令：

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

透明背景可用于预览和 WebM/VP9 类素材流；多数浏览器生成的 MP4 不保留 alpha 通道。
